第一次使用
1. 教练登录分配的教练账号，在学员页添加学员档案。
2. 在该档案“账号关联”中输入学员已有用户名，生成并复制邀请口令。
3. 学员登录自己的账号，在“接受教练邀请”处粘贴口令。
4. 关联成功后，学员可以向这位教练提交预约；教练在收件箱接受或拒绝。
5. 同一学员可接受不同教练邀请；各教练资料及课时分别隔离。
新建账号不按姓名自动关联，也不会收到既有Mock账号的数据。

维护与构建
npm run build:trial 只复制明确的公开静态文件到 .cloudflare/assets。
cloudflare/wrangler.jsonc 定义部署、静态绑定及后端地址，文件不含密钥。
npm run deploy:trial 构建并通过官方Wrangler发布；在验收通过后执行。
配置中的YUELIAN_BACKEND绑定指向yuelian-api，service_id为
01a199df-d580-7c31-956d-5882481ac045；其唯一目标为上述Mac后台。
当前Wrangler OAuth没有VPC资源授权，直接携带绑定上传会返回10196，不能当作发布成功。
本轮用现有Wrangler授权上传代码，再由已登录的账号控制台添加同一后端的绑定。
最终线上绑定、URL和源码配置一致；未扩大OAuth范围。后续部署必须保留该绑定，
不得为了绕过10196直接删掉正式配置中的vpc_services，否则HTTP请求将故意失败关闭。
若维护授权仍不支持VPC，使用账号控制台完成部署/绑定并重新验证公网接口；
本轮output中的bootstrap-worker.json仅为故障切换中间态，禁止当作正常发布配置。
YUELIAN_STANDALONE_BRIDGE_SECRET 必须为独立随机密钥，以Wrangler secret保存，
后端私有 runtime.env 保存相同值；它不得与原 YUELIAN_BRIDGE_SECRET 相同。
禁止将任意浏览器 oai-/x-user-/x-role 头作为身份；数据库session确定真正用户。
