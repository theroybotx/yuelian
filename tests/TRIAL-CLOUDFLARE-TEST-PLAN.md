# 个人 Cloudflare 封闭试用验收计划

日期：2026-11-02。状态：**已执行并发布独立邀请试用入口。54项按各自记录的测试层完成；公网功能通过使用本机既有代理，当前网络无代理直连 workers.dev 仍超时。不能据此声明所有访问环境均通过。最终证据、历史失败与网络限制见第16节。**

## 1. 本次交付边界

本次提供独立 Cloudflare 网页入口，由管理员通过受控本地工具创建 8 个普通业务账号。访客使用约练用户名、密码登录，不需要 ChatGPT 账号，不开放自行注册，不接入短信或邮件服务。这里的“管理员创建”指受控开通方式，不代表 8 个账号都获得教练、团队管理员或数据库管理权限。角色、显示名称、初始关联关系以开通清单为准。

既有 Sites 入口保留。Node/PostgreSQL 后端继续位于当前 Mac，保留已有数据库和业务权限模型。Cloudflare Worker 是独立网页及可信请求桥接入口，不把 PostgreSQL RLS 改写为 D1 权限，也不代表后端已经迁到云端。

独立桥接使用独立签名密钥和固定 audience `standalone:cloudflare-trial`。固定 audience 表示入口通道，不表示教练或学员身份。真实业务 actor 必须由数据库会话解析。匿名限流使用 Worker 从可信 Cloudflare 客户端 IP 派生的 HMAC `clientKey`；浏览器不能指定 actor、通道身份或这个限流键。业务会话不绑定 IP，移动网络变化不应使有效会话失效。

本次没有公开注册、邮件验证、短信验证、忘记密码自助流程、公开管理后台或自动发送账号凭据。不得把这些能力列为“通过”。

## 2. 环境、证据与安全约束

- 自动化写入、账号失效、限流耗尽、过期令牌、错误签名、停服和恢复测试只在独立 `yuelian_acceptance_*` 数据库及测试端口运行。不得重置、重新播种或做故障注入到 `yuelian_security`。
- 独立夹具至少包含教练甲/乙、学员甲/乙、跨教练关联学员、未关联学员和受限助教。夹具不依赖实际 8 个账号的密码，不把测试 fixture 的角色组合当成实际开通要求。
- 实际数据库部署前记录备份及关键表摘要。新增 8 个账号和清单明确要求的关联属于授权增量；对既有行按主键核对，不能因为总行数增加就误判旧数据被修改，也不能声称所有表完全未变。
- 公网验收使用独立新浏览器上下文，先不登录 ChatGPT。线上只做登录、读取、草稿生成/修改及退出；完整业务写入闭环在隔离库验收。若要线上提交真实预约，须在记录中单列其授权、对象和数据增量。
- 记录测试 ID、源码提交/摘要、环境、执行时间、预期、实际、状态和证据路径。修复后保留第一次失败，再追加定向回归；不同源码轮次不能合并冒充一次全量通过。
- 报告、截图、日志、命令行和测试产物不记录真实密码、会话 token、签名密钥、Cloudflare 凭据或数据库凭据。测试可以比较值或哈希，但输出只保留比较结果及脱敏元数据。
- 层级：U=单元/函数；W=真实 Workers 运行时桥接；A=隔离后端 API/PostgreSQL；B=浏览器；O=实际部署只读/草稿验收；R=静态及发布产物审查。人工审查、受控 API 浏览器测试与真实后端测试分别报告。
